# 批量修卡 playbook（多子代理并行）

> 只在一次修几十上百张卡时用；常规 sync 不读本文。操作口径见 `SKILL.md` §sync。

## 投影由父代理单写

多组子代理并行改卡时，任务书要写明「**子代理不改 INDEX.md**」。它们改了某卡 `>` 首行会让「INDEX 正投影」当场红灯，而被禁止改 INDEX 的子代理只能「加注绕过」（把现行名写在第二行），把不一致固化下来。

⇒ 收口顺序固定：**子代理只改卡 → 父代理跑 `qwiki-sync.py --write` 一次性同步 INDEX → 跑自检到全过 → commit**。

## 派工粒度

- 每组 ≤20 张卡 / ≤25 文件；任务书要求 **python 批量改写**（逐卡一条命令必撞子代理工具调用上限，只交付一半）。
- 截断返回的 `not_done` 就是断点接力的输入——按它重派剩余条目（附已备好的 `file:line` 与改法），别让新子代理从零核证。

## 一张卡占了多行

同一文件在 INDEX 表里出现 ≥2 次 → 合并为一行，子发现归卡片正文。
