## ⚙️ 本模板用法（生成卡片时，本节及以下整段删除）

### 这张卡记什么

**一次受控测量 + 据此的裁决。** 三类任务都落到这张卡：

```
优化任务  ──┐
对比测量  ──┼──►  一次测量（口径 → 数据 → 裁决）
竞品取证  ──┘
```

注意 **「优化」不能当形态名**：本库里相当一部分此类卡的结论是「测完决定不做」（候选关闭），"优化"预设了方向，装不下它。同理 **「实验」也偏窄**——有整类卡片只是测量、没改任何代码。

### 一条纪律

**任何数字都必须能追回口径。** 缺口径的读数不是知识，而是不可复核的字符串——**同一份数据换一个口径就能得出相反的结论**（同一天、同一台机器、同一个对象，换个口径结论就翻）。**本节不是形式，是这张卡值不值钱的分界线。**

### 好坏例

坏——数字都在，条件全无（等于没测，三个月后没人敢引用）：

```
## 数据
TCP TX 137 Mbps，UDP 98 Mbps 零丢包。
结论：优化有效，性能提升明显。
```

好——每个数字都能追回条件，且结论带边界：

```
## 口径
设备 <IP>（eth0 已摘，无并行 iperf） / AP <AP 型号> ch<信道> <带宽> / RSSI -38~-40
/ 同日交错 ABAB / 每点 120s / n=2 / 固件 commit <hash>

## 数据
| 臂 | TCP TX P1 | UDP TX | UDP 丢包 |
|---|---|---|---|
| 基线（池 250） | 118 Mbps | 96 Mbps | 18% |
| 改后（池 512） | 123 Mbps | 100 Mbps | 1.8% |

## 裁决
采纳。UDP 丢包 18%→1.8% 为主判据；TCP TX +4% 在噪声内（n=2 不足以判）。

## 局限 · 遗留
仅 AP <AP 型号> ch<信道> 单点；RSSI 优于 -45 时未测；**本结论不适用于 2.4G 段**。
```
