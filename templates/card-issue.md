## ⚙️ 本模板用法（生成卡片时，本节及以下整段删除）

### 伪代码写法

- 写成**正常流 vs 出错流对照**，不是单写"修法"——对照才看得出根因
- 关键行带真实符号名或 `file:line`，让读者能直接跳过去
- 只写机制相关的行，不搬真实代码（真实代码在 repo 里，会过时）
- 修法写成"切断了哪一环"，不写"加了判断"这种描述

### 好坏例

坏——复述文字、无对照、无锚点：

```
问题在于接收线程和中断处理没有正确同步，导致队列被重复处理。
```

好——对照 + 锚点 + 修法指向根因：

```
正常：
  busrx_thread:820  dequeue() -> len>0 -> 处理 -> 提交 netif_rx

出错：
  busrx_thread:820  dequeue() -> len==0 -> printk 风暴   ← 空队列未早退
  修法：len==0 时 goto exit，切断"空队列也打日志"这一环
```
