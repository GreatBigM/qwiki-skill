# ~/qwiki/ 目录结构

```
~/qwiki/                          ← Hermes 知识库（git 管理）
├── INDEX.md                     ← 全局知识目录，一张平表
├── ROUTING.md                   ← 检索链详细说明
├── personal/                    ← 个人笔记（自由格式）
│   └── <主题>.md
└── projects/<项目>/             ← 项目知识（平铺）
    └── <模块名>.md
```

## 与代码仓的关系

```
代码仓 /mnt/data/<项目>/
├── AGENTS.md                    ← 跨工具通用界面
├── .codegraph/                  ← 代码索引
└── workbench/                   ← 任务管理（独立域）
```
